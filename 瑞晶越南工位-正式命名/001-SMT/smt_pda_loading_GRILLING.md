## Q1: 什么触发物料上料流程？工单、工位、贴片机三者关系？

**结论 ✅ 已确认：**

- MES 下发工单（BOM + 工序顺序） → `smt_pda_loading` 拿到"需要装什么料、装到哪个槽位"
- 贴片机是消费者 — 不知道要什么料，只等有料才能跑
- `smt_pda_loading` 是中间核验关卡：操作员备料 + 扫码确认 → MES 记录 → 贴片机放行
- 如果核验未完成，贴片机不能开始贴装，且贴出来的板子无法追溯

---

## Q2: 核验的"通过/不通过"由谁决定？

**结论 ✅ 已确认：**

- `smt_pda_loading` Agent 本地判断：扫码结果 vs BOM → 决策"放行"或"拒绝"
- 同时写入 MES outbox，让 MES 知道"这批物料已核验完毕"
- 贴片机收到 MES 指令才开跑，不依赖本地 Agent 直接通信
- MES 离线时，Agent 缓存核验结果，恢复后上报

---

## Q3: 上料核验的范围 — 仅首次上料，还是持续在线？

**结论 ✅ 已确认（持续在线）：**

- `smt_pda_loading` 工位持续在线，不只是首次上料
- 监控飞达余量，处理中途换卷
- 贴片机换卷时，必须回传 `smt_pda_loading` 存档（扫码新卷 + 记录旧卷余量）
- 工位持续保持与 MES 的心跳和状态同步

## Q4: 飞达槽位分配表存在哪里？站位号是什么？

**结论 ✅ 已确认（来自 NPM Excel 规范）：**

- **槽位不是静态配置表**，而是动态绑定关系的一部分
- 绑定五元组：`工单号 + NPM机台码 + 飞达码 + 站位号 + 物料料号 + 批次号`
- NPM机台站位号示例：`2R`、`2L`、`1L`（贴片机上的物理槽位）
- 飞达码格式：前缀(FD/FT) + 规格宽度(08/12/16/32/TR) + 流水号(001...)
  - `FD` = 卷带电动飞达，`FT` = 托盘飞达
  - `FD08002` = 8mm电动卷带飞达第2支
- **防错校验（绑定时自动执行）：**
  - ①规格校验：扫码飞达码 → 自动解析载带规格 → 与 BOM 物料包装宽度比对，不一致则锁定站位弹窗报警
  - ②状态校验：维修/报废飞达扫码直接拦截禁止上机
  - ③类型校验：托盘飞达仅匹配托盘物料，卷带飞达不可绑定托盘料
  - ④重复校验：同一工单同一站位不可重复绑定飞达
- 工单完工/物料下料/换线后**自动解绑**
- 每笔绑定完整记录：上料时间、上料操作员、下料时间、下料操作员

## Q5: 物料消耗追踪 — 余量监控如何实现？

**结论 ✅ 已确认（来自 NPM Excel 规范）：**

- NPM机器**不直接反馈余量**（没有传感器直读）
- 追踪机制：
  - 操作员在 `smt_pda_loading` 扫码绑定时记录物料批次号和上料时间
  - MES 或 NPM 贴片机反馈已完成贴装数量
  - 系统根据 BOM 数量和已贴装数量**推算剩余**
  - 低于阈值时触发告警
- 换卷时：记录旧卷余量 + 新卷信息 → 系统确保连续性
- 无传感器自动上报机制

---

## Q6: 批次追溯

**结论 ✅ 已确认（来自 NPM Excel 规范）：**

- 每卷：料号 + 批次号 + 日期码 + 供应商
- 绑定时扫码 → 存档 → 贴装记录关联批次
- 每笔绑定永久存档，支持按**工单 / 机台 / 飞达 / 物料**多维度反向追溯
- 满足 ISO 与客户稽核要求
- 出问题时：根据 SN 查批次 → 锁定问题范围

---

## Q7: 异常场景

**结论 ✅ 已确认（来自 NPM Excel 规范）：**

- 料号不匹配 BOM → **拒绝，阻止上机**（锁定站位弹窗报警）
- 批次/日期码过期 → **拒绝**（规格校验锁定）
- 数量不足 → 允许上料但告警
- 换错槽位（重复绑定同一站位）→ **拒绝**（重复校验）
- 维修/报废状态飞达扫码 → **直接拦截**（状态校验）
- 托盘飞达绑定卷带物料 → **拒绝**（类型校验）
- MES 离线 → 本地缓存 outbox，恢复后上报
- 无编码飞达（台账中不存在）→ **禁止上机**

## Q11: 网络架构 — NPM 和 PDA 都连接哪里？

**结论 ✅ 已确认：**

- **NPM 贴片机** 通过工厂内网有线连接 `192.168.6.155:8080`（MES）
- **PDA**（`smt_pda_loading`）通过 WiFi 连接 `192.168.6.155:8080`（MES）
- 两者殊途同母 — 都连 MES（192.168.6.155:8080）
- 贴片机和 PDA **不直接通信**，都只跟 MES 交互

## 生命周期管理（来自 Excel）

- **新设备入库**：一物一码，扫码录入，编码终身不变
- **设备使用**：上料必须扫码绑定，无编码飞达禁止上料；换料必须扫码校验
- **维修/保养**：必须扫码登记；维修后校验编码完好性；更换配件记录到台账
- **设备报废**：标记编码失效；失效编码3年内不复用；拆除或销毁唯一码标签

## Q8–Q15：开工、上料和线长放行

**结论 ✅ 已确认：**

1. 生产计划在 MES 下达工单，PDA 显示当前工单和 BOM。
2. 操作员在 `smt_pda_loading` UI 点击“开始上料”。
3. PDA 进入飞达绑定模式，操作员按规定顺序完成扫码和物料安装。
4. 所有必需槽位通过防错校验后，系统进入“等待线长确认”状态。
5. 线长通过 UI 登录身份点击“确认放行”，不是用普通产品扫码代替批准。
6. MES 保存放行人、时间、工单、机台和完整绑定快照。
7. 未获得线长放行时，NPM 不得开始该工单。

> MES 是唯一权威数据源。NPM 和 PDA 均连接 `192.168.6.155:8080`，两者不直接通信。

### 建议采用的事件与命令

| 方向 | 名称 | 说明 |
|---|---|---|
| PDA → MES | `SMT_LOADING_STARTED` | 操作员点击开始上料 |
| PDA → MES | `SMT_SLOT_SCAN` | 单次机位/槽位/飞达/工号扫码 |
| PDA → MES | `SMT_FEEDER_BOUND` | 一个槽位完成绑定 |
| PDA → MES | `SMT_LOADING_READY` | 全部必需槽位完成并等待线长 |
| UI → MES | `SMT_LINE_LEADER_RELEASED` | 线长确认放行 |
| MES → PDA/NPM | `SMT_WORK_ORDER_RELEASED` | 工单已批准，可进入生产状态 |
| MES → PDA/NPM | `SMT_WORK_ORDER_BLOCKED` | 工单被暂停、撤销或校验失败 |

NPM 设备接口协议尚未从设备厂家文件确认，因此 MES 对 NPM 的最后一跳应通过设备适配器实现；业务事件名称保持不变，底层可以适配 HTTP、文件交换或厂家协议。

## Q16–Q18：余量、换卷和断网规则

**结论 ✅ 已确认：**

- 余量采用 **MES 推算 + 人工确认**。
- 推算依据：初始卷数量、BOM 单板用量、完成板数、抛料/损耗修正。
- 低余量预警后，操作员准备新卷。
- 换卷必须记录旧卷余量、旧卷下料时间、新卷料号/批次、操作员和新绑定时间。
- 新卷必须重新执行物料、防错、批次和飞达校验。
- MES 离线时 NPM **不能盲跑新工单或新绑定**；现场保持安全停机并保留本地待同步记录。
- 网络恢复后按原事件顺序重放，MES 确认后才能继续。

## Q19–Q21：异常和 NG 闭环

**结论 ✅ 已确认：**

| 异常 | 发现位置 | 处理路径 |
|---|---|---|
| 缺料 | 05 贴片机 | 返回 00 上料工位补料/换卷并重新绑定 |
| 飞达脱落 | 05 贴片机 | NPM 停机报警 → 00 重新绑定 → 线长重新放行 |
| 贴偏或贴装缺陷 | 06 SMT-AOI | 生成 NG → 维修站闭环维修 → 返回指定验证工位 → 再过 AOI |

- 维修站属于统一 MES 维修闭环，即使现场短时离线，也必须使用本地队列续传。
- NG 不得因离线或重新扫码而自动消失。
- 维修完成后仍需品质和线长批准、返站扫码接收，才允许 MES 复活 NG。
- PDA 绑定过程的基本扫码事件统一为 `SMT_SLOT_SCAN`，完整槽位绑定事件为 `SMT_FEEDER_BOUND`。

## Q22–Q30：批次、编码、扫码和存档

### 三层批次追溯

- 工单层：生产产品、版本、目标数量和 BOM。
- 班次层：班次、线别、人员和生产时间。
- 料卷层：供应商、料号、批次、日期码和实际使用槽位。
- 最终必须支持 `成品/PCB SN → 工单 → 班次 → NPM → 槽位 → 飞达 → 料卷批次` 反向追溯。

### SMT 工位编码

| 工位号 | 工站码 | 名称 |
|---|---|---|
| 00 | `smt_pda_loading` | PD扫码上料 |
| 01 | `smt_laser_marking` | 镭雕机 |
| 02 | `smt_auto_insertion` | AI插件机 |
| 03 | `smt_printer` | 印刷机 |
| 04 | `smt_spi` | SPI锡膏检测 |
| 05 | `smt_placement` | 贴片机 |
| 06 | `smt_aoi` | SMT-AOI |

### 最终扫码顺序

1. MES 提供当前工单号和 BOM，不由操作员手工录入。
2. 扫机位号。
3. 扫槽号。
4. 扫飞达号。
5. 扫物料料卷标签，取得料号、批次、日期码等信息。
6. 扫操作员工号。
7. 操作员确认绑定。
8. 全部槽位完成后，由线长在 UI 确认放行。

### 防错校验

- 飞达规格与 BOM 物料包装规格一致。
- 飞达状态可用，非维修、报废、停用状态。
- 飞达类型与物料包装类型一致。
- 同一工单、机位和槽位不存在冲突绑定。
- 物料批次、日期码和保质期有效。
- 物料属于当前工单 BOM，禁止多料、错料和替代料未经批准。
- 操作员和线长具有相应岗位权限。
- 工单处于有效、已下达且未暂停状态。

### 永久存档字段

- 工单号、线别、班次
- NPM 机位号、槽号
- 飞达号、飞达规格和状态
- 物料料号、供应商批次、日期码
- 上料操作员及上料时间
- 线长编号及确认时间
- 下料时间、下料操作员、旧卷剩余量
- 换卷原因和新旧料卷关系
- 防错校验结果、拒绝原因和报警记录
- MES 接收时间、本地事件 ID、同步状态和内容哈希

## Q31–Q36：身份、状态和 PDA UI

**结论 ✅ 已确认：**

- 操作员工号通过工牌扫码取得。
- 线长身份通过受控 UI 登录/权限验证取得，批准记录不可由普通操作员代签。
- 待机状态显示：等待工单、MES 连接状态、NPM 状态。
- 工单到达后显示：工单、BOM、待绑定槽位和“开始上料”按钮。

### PDA UI 优先级

1. 顶部状态栏：工单、L001、00上料工位、MES/离线状态。
2. 飞达绑定主操作区：扫码步骤、当前输入和每步通过/拒绝状态。
3. BOM 与槽位清单：应装、已装、缺失、冲突。
4. 余量监控：估算余量、预警和换卷入口。
5. 线长放行区：仅全部校验通过且有权限时可用。
6. 报警与日志区：异常、换卷、解绑、离线续传状态。

## Q37：11 类报警

| # | 报警类型 | 触发条件 |
|---:|---|---|
| 1 | 飞达状态异常 | 未入库、维修中、已报废或被停用 |
| 2 | 规格不匹配 | 飞达宽度/规格与 BOM 物料要求不一致 |
| 3 | 重复或冲突绑定 | 槽位已占用、飞达已绑定到其他活动工单 |
| 4 | 批次过期 | 日期码、保质期或批准期限无效 |
| 5 | 飞达脱落 | NPM 槽位/飞达检测异常并停机 |
| 6 | 工单异常 | 工单暂停、撤销、过期或版本变化 |
| 7 | 物料追溯缺失 | 料卷标签无法关联供应商批次 |
| 8 | 飞达余量耗尽 | MES 估算余量达到零或低于阈值 |
| 9 | 上料超时 | NPM 等料超过配置阈值 |
| 10 | 操作员权限异常 | 未注册、无上料资格或身份失效 |
| 11 | MES 离线 | 心跳超时，暂停新绑定和生产放行 |

报警必须记录工位、工单、机位、槽位、飞达、物料、人员、触发时间、确认人、解除时间和处理结果。关键报警采用声光提示；只有原因消除或授权人员确认后才能解除。
