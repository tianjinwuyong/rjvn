# PDA Bricks

- `PDA-SCN-001 Scan Surface` — camera/laser scan, torch, focus and feedback.
- `PDA-IDN-001 Operator + Device Identity` — login, device ID, host/IP and shift.
- `PDA-RCV-001 Material Receipt` — supplier, lot, quantity, IQC documents and labels.
- `PDA-PUT-001 Put-away` — location QR, coordinates, capacity and illegal-placement warning.
- `PDA-MOV-001 Material Movement` — source/destination double scan and movement history.
- `PDA-ISS-001 WO Issue` — issue quantity to work order and remaining balance.
- `PDA-RET-001 Return + Partial Box` — partial quantity, reseal, relabel and stock reconciliation.
- `PDA-CNT-001 Cycle Count` — blind count, variance, approval and adjustment.
- `PDA-OFF-001 Offline Queue` — idempotent local queue and safe synchronization.
- `PDA-PRT-001 Mobile Printing` — material, pallet, rack and area QR labels.
