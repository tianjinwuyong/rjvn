# Shared Contracts

Contract families:

- Facts: scan, result, alarm observation, operator action, device health.
- Commands: allow, block, mark, remove, print, dispatch, acknowledge, close.
- Policies: route, NG, repair, authorization, offline, language and UI behavior.
- Identity: product, work order, station, component, employee, device, material and location.

Contracts are versioned and transport-neutral. Each producer keeps its original source reference; each MES decision includes reason, rule version and timestamp.
