# MES Management Bricks

## Product-centered bricks

- `MES-PRD-001 Product Genealogy` — SN, mother/daughter/sibling, case and pallet genealogy.
- `MES-PRD-002 Work Order Control` — release, station readiness, quantity, completion and exception.
- `MES-PRD-003 Route Engine` — next-station decision and controlled exemption.
- `MES-PRD-004 Result Ledger` — immutable cycle history and explicit final-record projection.
- `MES-PRD-005 Binding Management` — shell/case/pallet binding with domain separation.

## NG-centered bricks

- `MES-QLT-001 NG Trace` — defect history, current state and product impact.
- `MES-QLT-002 Alarm Lifecycle` — new-only alert, acknowledge, response, processing time and closure.
- `MES-QLT-003 Repair Order` — trigger, dispatch, receive, diagnose, repair, retest and close.
- `MES-QLT-004 Retest Governance` — authorization, attempt history and final-record rule.
- `MES-QLT-005 Scrap Governance` — approval, disposition and WMS impact.

## Platform bricks

- Policy registry, station registry, component registry, authorization, audit ledger, notifications, SLA/escalation, configuration versions, diagnostics and reporting.
