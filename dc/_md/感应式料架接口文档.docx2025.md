1. 点亮或熄灭指定料架所有空库位

输入

接口地址：http://10\.100\.29\.151:8093/api/shelf/LightOnAllEmptyLocationGY

请求方式：POST

字段名

必要字段

字段类型

内容说明

参数描述

shelfCode

是

String

料架号

库位码前五位

color

是

Int

亮灯灭灯

0：灭灯,1：亮灯

JSON 格式示例： 

\{ 

"shelfCode": "L001A",

"color": 0

\}

输出

字段名

必要字段

字段类型

内容说明

参数描述

Result

是

String

返回结果

OK:成功、NG：失败

ErrorCode

是

String

异常代码

Message

是

String

错误内容

JSON 格式示例： 

OK 结果： 

\{ 

"Result": "OK", 

"ErrorCode": "OK", 

"Message": "OK" 

\} 

NG 结果: 

\{ 

"Result": "NG", 

"ErrorCode": "300", 

"Message": "料架号不存在" 

\}
