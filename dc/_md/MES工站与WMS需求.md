| 大模块 | 功能分类 | 核心功能点 | 功能详细描述 | 主要价值/目的 | 备注 |
| 一、仓库管理 | 1. 基础数据管理 | 1.1 物料主数据管理 | 维护物料编码、名称、规格、供应商、存储条件、安全库存等基础信息。 | 数据标准化、追溯基础 | 必需 |
|  |  | 1.2 库位精细化管理 | 对仓库、区域、货架、库位进行编码和数字化管理，定义库位属性（如待检区、良品区）。 | 实现物料精确定位 | 必需 |
|  |  | 1.3 批次/序列号管理 | 为每批物料生成/记录唯一批次号，并强制关联生产/到货/有效期。对关键物料管理唯一序列号。 | 实现全流程精确追溯，为FIFO奠定基础 | 必需 |
|  | 2. 入库管理 | 2.1 采购订单收货 | 扫描采购单号或物料条码进行收货，系统自动比对订单，支持超收、欠收处理。收货后物料状态自动变为“待检”。 | 提高收货效率与准确性，防错 | 必需 |
|  |  | 2.2 生产退料接收 | 扫描工单号和物料码，接收生产线退回的物料，记录退料原因并更新库存。 | 工单物料结算，库存准确 | 必需 |
|  |  | 2.3 智能上架指导 | IQC合格后，系统通过PDA推荐最优上架库位，指导仓管员扫描上架，绑定物料与库位。推荐逻辑可支持FIFO布局。 | 提高上架效率，优化库存布局 | 必需 |
|  | 3. 出库管理 | 3.1 工单发料 | 根据MES工单和BOM生成拣货单，系统按FIFO规则指导仓管员到指定库位拣选物料，扫描确认后扣减库存。 | 确保按单、按量、按序发料，防错 | 必需 |
|  |  | 3.2 拣选优化（播撒/播种） | 支持为多个工单集中拣选（播撒）或按物料类型拣选再分发（播种）。系统仍需在具体拣选时遵循FIFO。 | 提高拣选效率 | 可选 |
|  |  | 3.3 退供应商出库 | 创建退货单，扫描物料批次出库，更新库存并通知相关部门。 | 规范退货流程 | 必需 |
|  |  | 3.4 销售退货接收 | 创建销售退货单，扫描退回的成品/物料，系统将其置为“退货待检”状态，并触发质量检验流程。 | 完成销售到仓库的闭环管理，规范退货处理 | 必需 |
|  | 4. 库存管理 | 4.1 实时库存看板 | 提供按物料、库位、批次、状态等多维度的实时库存查询。 | 库存可视化 | 必需 |
|  |  | 4.2 盘点管理（明盘/盲盘/循环盘点） | 通过PDA扫描进行盘点，系统生成盘点单与差异报告。支持按ABC分类制定循环盘点计划。 | 保证账实相符 | 必需 |
|  |  | 4.3 库存转移与调整 | 记录仓库内部库位间的物料移动。支持库存数量的手动调整并记录原因。 | 库存动态管理 | 必需 |
|  |  | 4.4 库存锁定与预警 | 对有质量问题的库存进行冻结。当库存低于安全库存或高于上限时自动预警。 | 防止误用、避免断料或积压 | 必需 |
