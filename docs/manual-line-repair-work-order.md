# Manual-line repair work-order format

## Authority

MES creates and owns the repair work order. The Agent may request creation from an approved trigger, display the order, scan and collect facts, and append evidence. The Agent must not invent a route, change the retest limit, or finalize disposition.

## Field rules

| Field group | Owner | Rule |
|---|---|---|
| `workOrderId`, `eventId`, `issuedAt` | MES | Immutable and idempotent; never regenerated by an Agent |
| `sourceStation`, `repairStation` | MES | Derived from the published route; Agent may only report observed host/IP facts |
| `product.sn`, parent/child SNs | MES + Agent fact | Must match the scan and product binding; reject mismatches |
| `bucket.bucketQr`, quantities | MES + handover facts | Bucket QR, SN, and quantity must reconcile at issue, receipt, and return |
| `trigger` | MES | Records why the order was issued: button, time, quantity, period, or configured combination |
| `ng` and `evidenceRefs` | Station/repair facts | Append-only; later PASS never overwrites the original NG |
| `route` | MES | Versioned; Agents cannot edit destination or retest limit |
| `audit` | MES | Records actor, role, timestamps, and configuration version |

## Trigger semantics

- `MANUAL_BUTTON`: authorized human presses the repair-dispatch button.
- `TIME`: elapsed time reaches the MES-published threshold.
- `QUANTITY`: pending NG quantity reaches the MES-published threshold.
- `PERIOD`: the configured dispatch period becomes due.
- `ANY`: any enabled condition issues the order.
- `ALL`: every enabled condition must be satisfied.

The trigger model is specified in [repair_order_triggers.qnt](../tools/quint/repair_order_triggers.qnt). The route model is specified in [route_rules.qnt](../tools/quint/route_rules.qnt).

## Offline behavior

When MES is unavailable, the Agent may append a local request/evidence record to the Outbox, but it must not issue a new formal MES work order, change routing, change thresholds, or grant final release. After recovery, MES creates or rejects the formal order using the original `eventId`.
